Joysen Tattoo Studio — V17

New in V17:
- Thin gold page-scroll progress indicator at the top of the viewport.
- Floating Back to Top button appears after scrolling down.
- Button respects the user's reduced-motion preference.
- Scroll progress updates are requestAnimationFrame-throttled and passive-scroll-listener based.

Run on Windows:
1. Extract the ZIP.
2. Open the project folder.
3. Run START-WEBSITE.bat.

Requirements: Node.js 22 LTS and npm 10 or later.
The V17 changes are source-level updates. A production build and browser QA have not been run in this environment.
