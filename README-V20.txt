V20 — ONLINE IMAGE PLACEHOLDER MILESTONE

This update adds a photographic hero and image-led portfolio preview using online reference images. These are temporary external examples, NOT Joysen's actual work. The gallery visibly labels them as external references so visitors are not misled.

Replace the remote URLs in src/App.tsx (gallery array and Hero component) with Joysen-owned/approved local images before public launch. See ONLINE-IMAGE-ATTRIBUTION-V20.md for source notes and permissions cautions.

Images load from external websites and therefore require internet access. All previous V19 project features and supplied studio interior assets are retained.

Run with Node.js 22 LTS:
