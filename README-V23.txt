## Run
1. Extract the ZIP.
2. Open the `project` folder.
3. Use Node.js 22 LTS.
4. Double-click `START-WEBSITE.bat`.

Or run `npm install` and then `npm run dev`.

## Content/image notes
- Studio photos in the hero, about and aftercare sections are the user's supplied Joysen studio images.
- External tattoo reference images are not presented as verified Joysen customer work.
- Pricing and studio facts are reproduced from the information supplied for this project; confirm current details with Joysen before publishing.
