Joysen Tattoo Studio — V18

New in V18 — mobile contact and accessibility polish:
- Adds a fixed mobile-only Call Studio and WhatsApp action bar.
- Uses the supplied studio phone number (088977 70464) for both actions.
- WhatsApp opens a prefilled enquiry; the visitor must review and press Send.
- Adds consistent keyboard-visible focus outlines to links, buttons, form controls and FAQ summaries.
- Reserves safe-area space for mobile bottom navigation and moves Back to Top above the contact bar.

Retained from previous milestones:
- Joysen branding and supplied logo.
- Services, source-provided pricing notes and indicative estimator.
- WhatsApp enquiry form, FAQs, studio photo gallery and walkthrough video.
- Scroll reveal, progress bar and Back to Top.

Run:
1. Extract this ZIP.
2. Open the project folder.
3. Ensure Node.js 22 LTS is installed.
4. Run START-WEBSITE.bat.

Note: The mobile action bar is shown at viewport widths up to 760px. It has not been browser-tested in this environment. Studio portfolio imagery is still not included; the gallery uses the supplied studio-interior photos, not tattoo-work examples.
