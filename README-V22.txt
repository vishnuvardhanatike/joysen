JOYSEN TATTOO STUDIO — V22

Changes in this milestone:
- Removed the large decorative “A” glyph from the home hero image.
- Added image-led visuals to all nine service cards. They are illustrative external references, not verified Joysen portfolio work. The Piercing card uses a supplied studio interior image.
- Rebuilt the services area as a horizontal left-to-right carousel with scroll snapping, previous/next controls, and a “View all services” toggle that expands every option into a grid.
- Added responsive layouts and reduced-motion support.

Run:
1. Extract the ZIP.
2. Open the project folder in a terminal.
3. Use Node.js 22 LTS.
4. Run: npm ci
5. Run: npm run dev

Important:
- Online service-card image URLs require an internet connection and may be subject to third-party hotlinking or licensing restrictions. Replace them with Joysen-owned or licensed photos before publishing.
- The images are not represented as Joysen customer work or artist portraits.
- Production build could not be verified in this environment because npm dependency installation timed out.
